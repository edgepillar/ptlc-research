## What the observations establish

A successful prior call establishes behavior for that call under its selected
runtime premises. Retaining an absolute executable path does not retain the
file, its future contents or its future execution behavior. Existence and
execute permission checks refuse a missing entry but do not distinguish a
substituted executable that returns a well-formed result.

The test-only file digest and identity comparisons expose the substitution.
Five explicit digest acquisitions include four compiled native file reads and
one synthetic script read. They are separate from existing worker-profile artifact
observations, whose selected acquisition count stays unchanged. These test-only
comparisons are not production pin enforcement, source authentication or an atomic
measurement-to-launch guarantee. The synthetic replacement does no curve
arithmetic. A bound canonical receipt authenticates neither its claim nor the
program that produced it. This control adds selection history to the earlier
[receipt and durable reload controls](EXCHANGE_VERIFIER_TRUST_BOUNDARY.md);
it does not duplicate their journal retentions or change their conclusions.
