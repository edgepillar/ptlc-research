# Partial original custody without recovery admission

This is an offline comparison for three separately selected public synthetic
states: charged work with no retained result; a retained public long result with
no retained long original; and an exact retained long original. It is not an
executed journal interruption experiment or a durable recovery backend.

The immutable interface binds complete fixed terms, the exact public adaptor
pair, exact remote short bytes, charged work and prior evidence. Missing result
and original fields are explicit nulls. They remain
`NOT_RETAINED_OR_NOT_CREATED`; this does not establish whether an interrupted
worker ran, returned a result or lost it. A caller's COMPLETE work label without
retained output still supplies no output custody. UNKNOWN and FAILED work also
stay charged. Disclosure remains possible for every selected remote short.

The source rationale is the unchanged reference journal's ordering at research
baseline `f518235b5726987166f984884b3cbd1897790ea0`:
`remote-short`, trusted synthetic observation, `recovery-admitted`, public worker,
`recovered`, then `original`. Charge retention can precede worker execution and
both output records. A retained result can precede retained original bytes. This
ordering is a source finding, not fresh crash, disk or journal execution evidence.

The frozen complete authority query requires both original envelopes. This
separate encoding deliberately provides no conversion that fills an absent long
original from a fixture, infers unobserved output, constructs a replacement or
resets work. A fixture's known long completion is used only for the separately
selected result-present states. It is never read into the absent-result state.

Both earlier selected source-refusal records are retained as opaque claims. A
new bounded source-label frame binds the entire selected partial state, including
its missing fields, prior charges, evidence and challenge. Supported, unavailable,
unknown and contradicted labels cannot change the selection. Supported zero
evidence digests remain forgeable. Neither frame authenticates a source, proves
current funding, establishes momentum finality or supplies a trusted observation
callback. Native refusal/query contexts remain NOT_COMPOSED.

Selection validation checks public signature encodings and envelope membership,
not signature mathematics. It binds the exact fixed terms and public pair by
the existing verification-context domain. The separate fresh Rust public worker
qualification must verify those same fixture terms, pair and completions. That
gate does not authenticate application signing custody, chain observation or
the new hypothetical interruption cuts. This module never invokes a worker.

The pure object has no file, journal, clock, network, worker or release operation.
All results remain HOLD with recovery action NONE. Exact raw claim replay returns
the same object and supplies neither new evidence nor freshness. Comparison with
an independently retained later object refuses earlier bytes. A coherent older
object and matching older bytes still pass their own comparison: external restore
fencing remains UNFILLED. Hashes do not make local history authoritative.

The selected finite model compares abstract fixture filling, equating a public
result with a retained original, and retaining the partial hold. Across three
cuts, two prior charge counts and six claim orders, each policy covers 36
schedules and 180 transitions. The first two policies invent original custody
in 24 and 12 schedules, and permit 12 and 6 new abstract entries. The retained
hold does neither. These effects are counters only; no worker or envelope is
constructed. Every policy exposes 36 coherent old-copy losses. This bounded
enumeration is not an unbounded security proof or funded liveness proof.

Bounds are 16 charged attempts, eight distinct prior evidence blobs of at most
512 bytes, eight raw claims of each kind, 12 JSON levels and 128 KiB total framing.
Invalid fields, duplicate identifiers, changed short-byte bindings, cross-cut
claims, exhausted claim bounds and noncanonical encodings refuse while leaving
the prior immutable object unchanged. A retained original must match the exact
selected public result; result availability never creates original custody.
