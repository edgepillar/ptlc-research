complete cooperatively. Registration may mutate its registry before escaping,
but must not corrupt creation records. The same retained Python object returned
again by a factory is refused without another close; this is no opaque native
alias detector. Allocation before retention, arbitrary interruption around the
attempt mark or outcome recording, corrupted records and incomplete report

native retirement, and an escaped attempt remains incomplete. No atomic/durable
