## Public data included in the repository

### BIP340 verification vectors

`tests/fixtures/bip340_public_vectors.json` contains the public verification fields from all 19 rows of the [official CSV](https://github.com/bitcoin/bips/blob/927b6de9915c9262615a6399de51b200f81e5aa4/bip-0340/test-vectors.csv) at Bitcoin BIPs commit `927b6de9915c9262615a6399de51b200f81e5aa4`. The JSON records the source URL and original CSV SHA-256. The secret-key and auxiliary-randomness columns are omitted; the public verification values and expected results are retained.

The BIP340 authors are Pieter Wuille, Jonas Nick and Tim Ruffing. The [test-vector licensing paragraph](https://github.com/bitcoin/bips/blob/927b6de9915c9262615a6399de51b200f81e5aa4/bip-0340.mediawiki#test-vectors-and-reference-code) offers BSD-2-Clause, MIT or CC0-1.0. This fixture uses **CC0-1.0**, not the project MIT license. See the [CC0 1.0 legal text](https://creativecommons.org/publicdomain/zero/1.0/legalcode.en). No BIP reference implementation is included.

The private test seed is omitted. RFC 8032 was published in January 2017 in the IRTF stream and identifies S. Josefsson and I. Liusvaara as its authors.

Section 8(g) excludes the separate section 4 BSD code-component license for IRTF documents; this notice therefore does not label the vector BSD-licensed.

### Locally generated public fixtures

`qualification/fixtures/completed_signatures.json`, `qualification/fixtures/bitcoin_transactions.json`, `qualification/fixtures/nonce_rounds.json` and `qualification/fixtures/authentication.json` are synthetic outputs generated by the local qualification tests through the pinned libraries. `tests/fixtures/session_terms.json` incorporates their public fields with fictional session terms. These are distinct from the two upstream verification datasets above. Their generation does not establish security, chain funding or permission to use the public test inputs with funds.

`qualification/fixtures/enrollment_signature.json` and the separate
`qualification/fixtures/governor_signature.json` likewise contain local
synthetic public verification outputs through the existing locked library.
`qualification/fixtures/governor_contract.json` is the separately retained
unsigned framing vector. These original project fixtures retain the project MIT
license. Their public synthetic scalar tags occur only in qualification tests,
never as secret-key fields in these fixtures or as production signer material.
No new third-party dataset or dependency source is included by Stage 38.

Optional or alternate-target lockfile entries are not evidence that those packages execute in every build.
